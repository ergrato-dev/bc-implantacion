# 📚 Semana 08 — Mantenimiento, Soporte y Capacitación

> 🚧 Esqueleto — contenido de teoría, prácticas y proyecto pendiente.

---

## 🎯 Objetivos de Aprendizaje

Al finalizar esta semana, el aprendiz será capaz de:

1. Diseñar un plan de mantenimiento: parches, actualización de imágenes y dependencias
2. Automatizar actualizaciones de dependencias con Dependabot o Renovate
3. Definir un modelo de soporte por niveles (N1-N3)
4. Diseñar un plan de capacitación a usuarios con objetivos y materiales
5. Elaborar ayudas en línea: FAQ, guía rápida y tutoriales en Markdown

## 📝 Contenidos

- Tipos de mantenimiento: correctivo, preventivo, adaptativo, perfectivo

- Plan de capacitación: objetivos, técnicas de comunicación oral, materiales
