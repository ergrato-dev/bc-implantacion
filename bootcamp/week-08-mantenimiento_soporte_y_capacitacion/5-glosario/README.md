# 🎓 Glosario — Semana 8

| Término | Definición breve |
|---|---|
| **Mantenimiento correctivo** | Corregir un defecto del software |
| **Mantenimiento preventivo** | Evitar problemas futuros: parches, actualizaciones, limpieza |
| **Mantenimiento adaptativo** | Adaptar el software a un cambio del entorno |
| **Mantenimiento perfectivo** | Mejorar algo que ya funciona |
| **EOL (fin de soporte)** | Fecha desde la cual un componente deja de recibir parches |
| **Ventana de mantenimiento** | Periodo acordado para tareas que interrumpen el servicio |
| **Dependabot** | Servicio de GitHub que propone actualizaciones de dependencias por *pull request* |
| **Renovate** | Alternativa de código abierto a Dependabot |
| **CVE / GHSA / PYSEC** | Identificadores públicos de vulnerabilidades |
| **Severidad** | Gravedad de una vulnerabilidad: baja, media, alta, crítica |
| **`pip-audit` / `npm audit`** | Auditan dependencias de Python y Node contra bases de vulnerabilidades |
| **Trivy** | Escáner de vulnerabilidades de imágenes de contenedor |
| **`unattended-upgrades`** | Instala solas las actualizaciones de seguridad de Ubuntu |
| **`reboot-required`** | Archivo que indica que una actualización necesita reiniciar |
| **Mesa de ayuda** | Primer punto de atención a usuarios (N1) |
| **Escalamiento** | Pasar un caso a un nivel superior con toda su información |
| **Incidente** | Algo que funcionaba dejó de funcionar |
| **Solicitud** | Pedido de algo nuevo o de un cambio |
| **Prioridad** | Combinación de impacto y urgencia (P1 a P4) |
| **SLA** | Acuerdo de nivel de servicio con el cliente |
| **SLO** | Objetivo interno medible del servicio |
| **SLI** | Medición real de un indicador del servicio |
| **Runbook** | Procedimiento paso a paso para una situación conocida |
| **Análisis sin culpables** | Revisión de un incidente enfocada en el sistema, no en personas |
| **Objetivo observable** | Lo que una persona podrá hacer, de forma comprobable, tras capacitarse |
| **Modelo de Kirkpatrick** | Niveles para evaluar una capacitación: reacción, aprendizaje, aplicación, resultados |
| **Guía rápida** | Ayuda breve con las tareas diarias |
| **FAQ** | Preguntas frecuentes con respuestas cortas |
