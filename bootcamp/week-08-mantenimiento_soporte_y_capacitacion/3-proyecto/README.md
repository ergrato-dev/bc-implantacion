# Proyecto Semana 8 — Mantenimiento, Soporte y Capacitación

## 📋 Instrucciones

Completa la sección 9 del Plan de Implantación de tu proyecto real usando
[`starter/entregable-s08-mantenimiento-soporte-y-capacitacion.md`](starter/entregable-s08-mantenimiento-soporte-y-capacitacion.md).

En el repositorio del proyecto:

- `.github/dependabot.yml` adaptado a los ecosistemas del proyecto
- Formulario de reporte de fallas (`.github/ISSUE_TEMPLATE/`)
- `docs/runbooks/` con al menos dos runbooks, uno por cada alerta crítica del monitoreo
- `docs/ayuda/guia-rapida.md` y `docs/ayuda/preguntas-frecuentes.md`, enlazadas desde el README
  y, si es posible, desde la propia aplicación

En el servidor: actualizaciones de seguridad automáticas y la revisión rutinaria programada.

Y una prueba real: alguien de otro equipo sigue tu guía rápida y uno de tus runbooks sin
preguntarte nada; corriges lo que falló.

## ❓ Preguntas Guía

- ¿Qué componente de tu proyecto llega primero a su fin de soporte? ¿Cuándo empiezas a planearlo?
- ¿Quién de tu equipo cubre cada nivel de soporte? ¿Y cuando esa persona no esté?
- ¿Qué tiempos de respuesta puedes cumplir de verdad con las personas que tienes?
- ¿Quiénes usarán tu software y qué debe saber hacer cada uno el primer día?

## ✅ Checklist de Cierre
