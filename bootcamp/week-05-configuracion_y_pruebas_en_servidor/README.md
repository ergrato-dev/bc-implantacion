# 📚 Semana 05 — Configuración y Pruebas en Servidor

> 🚧 Esqueleto — contenido de teoría, prácticas y proyecto pendiente.

---

## 🎯 Objetivos de Aprendizaje

Al finalizar esta semana, el aprendiz será capaz de:

1. Separar configuración por ambiente con variables de entorno
2. Configurar los servicios requeridos: servidor de aplicaciones, base de datos, proxy
3. Definir healthchecks y smoke tests posteriores al despliegue
4. Ejecutar la migración de datos local → nube siguiendo el plan de la semana 2
