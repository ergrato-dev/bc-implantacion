# 📚 Semana 10 — (Opcional) IaC y Automatización

> 🚧 Esqueleto — contenido de teoría, prácticas y proyecto pendiente.

---

## 🎯 Objetivos de Aprendizaje

Al finalizar esta semana, el aprendiz será capaz de:

1. Aprovisionar un servidor con cloud-init
2. Convertir el plan de instalación en un playbook de Ansible idempotente
3. Conocer infraestructura como código con OpenTofu / Terraform

---

## 🧭 Trazabilidad RAP

| C2, C3 | P1, P5 |

**Criterios de evaluación:**

- **CE-1** — Prepara la plataforma tecnológica, con base en las características del sistema operativo seleccionado
- **CE-5** — Elabora el plan de instalación de acuerdo con las características del software a implantar

## 📝 Contenidos

- Infraestructura como código: concepto, idempotencia
- cloud-init para el primer arranque
- Ansible: inventario, playbooks, roles
- Introducción a OpenTofu / Terraform
- Práctica: playbook que instala la app de referencia en un Ubuntu limpio
