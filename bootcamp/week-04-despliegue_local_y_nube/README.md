# 📚 Semana 04 — Despliegue Local y en la Nube

> 🚧 Esqueleto — contenido de teoría, prácticas y proyecto pendiente.

---

## 🎯 Objetivos de Aprendizaje

Al finalizar esta semana, el aprendiz será capaz de:

1. Preparar una liberación versionada (tag + imagen de contenedor)
2. Organizar archivos y servicios en un servidor Ubuntu con Docker Compose
3. Desplegar en PaaS (Render) con base de datos gestionada (Neon / Supabase)
4. Explicar IaaS, PaaS y SaaS y estimar costos con las calculadoras de AWS, Azure y GCP
5. Documentar el procedimiento de despliegue como parte del plan de instalación
