# 🎓 Glosario — Semana 4

| Término | Definición breve |
|---|---|
| **Liberación (release)** | Estado del software convertido en versión identificable, reproducible e instalable |
| **SemVer** | Versionado semántico: `MAYOR.MENOR.PARCHE` |
| **Etiqueta Git (tag)** | Nombre fijo que apunta a un commit exacto |
| **Artefacto** | Resultado instalable de una liberación: imagen, paquete, instalador |
| **Etiqueta de imagen** | Nombre de versión de una imagen de contenedor (`biblioteca:1.1.0`) |
| **`latest`** | Etiqueta móvil por defecto de Docker; no identifica una versión concreta |
| **Notas de versión / CHANGELOG** | Registro de qué cambió en cada versión y qué hacer al actualizar |
| **Registro de imágenes** | Servicio que almacena y distribuye imágenes (GHCR, Docker Hub) |
| **`docker save` / `docker load`** | Exportar una imagen a un archivo e importarla en otro equipo |
| **Política de reinicio** | Regla que indica a Docker si reinicia un contenedor detenido |
| **Rollback** | Volver a la versión anterior |
| **Expandir y contraer** | Técnica de migraciones compatibles: agregar primero, borrar en una versión posterior |
| **Cloud computing** | Recursos de cómputo bajo demanda, pagando por uso, a través de Internet |
| **IaaS** | Infraestructura como servicio: máquinas virtuales, redes, discos |
| **PaaS** | Plataforma como servicio: ejecuta tu código o contenedor |
| **SaaS** | Software como servicio: aplicación lista para usar |
| **DBaaS** | Base de datos gestionada como servicio |
| **Responsabilidad compartida** | Reparto de tareas de seguridad y operación entre proveedor y cliente |
| **Nube pública / privada / híbrida** | Modelos de despliegue según quién usa la infraestructura |
| **Región** | Ubicación geográfica de los centros de datos de un proveedor |
| **Vendor lock-in** | Dependencia de servicios propietarios que dificulta cambiar de proveedor |
| **Free tier** | Plan gratuito con límites de uso |
| **Arranque en frío** | Demora de la primera petición cuando el servicio estaba suspendido |
| **Scale to zero** | Suspender un servicio sin actividad para no consumir recursos |
| **Alerta de presupuesto** | Aviso del proveedor cuando el gasto supera un monto definido |
