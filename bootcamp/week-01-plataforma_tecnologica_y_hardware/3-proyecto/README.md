# Proyecto Semana 1 — Ficha Técnica y Matriz de Requisitos

## 📋 Instrucciones

Este entregable abre el **Plan de Implantación** de tu proyecto real: es la sección 1 de
[`docs/plan-implantacion-template.md`](../../../docs/plan-implantacion-template.md).

1. Copia `docs/plan-implantacion-template.md` al repositorio de tu proyecto como
   `docs/plan-implantacion.md`.
2. Completa la sección 1 usando [`starter/entregable-s01-ficha-tecnica.md`](starter/entregable-s01-ficha-tecnica.md)
   como guía detallada.
3. Agrega `scripts/verificar-requisitos.sh` adaptado (práctica 02) al repositorio del proyecto.
4. Ejecuta el script en un servidor Linux y pega la salida en la ficha.

## ❓ Preguntas Guía

- ¿Qué servicios componen tu proyecto y cuánta RAM consume cada uno en reposo y con carga?
- Si el cliente quisiera alojar el proyecto en sus instalaciones, ¿qué formato de servidor y qué
  nivel RAID recomendarías? ¿Por qué?
- ¿Hay algún componente cuya licencia genere costo o restricción?
- ¿Hasta qué fecha tiene soporte el sistema operativo que elegiste?

## ✅ Checklist de Cierre

- [ ] Sección 1 del Plan de Implantación completa, sin campos vacíos
- [ ] Requisitos mínimos **y** recomendados, con el cálculo de margen visible
- [ ] Inventario de software con versión y licencia de cada componente
- [ ] Script de verificación en el repositorio del proyecto, con salida real pegada en la ficha
- [ ] Sin IPs, hosts, usuarios ni contraseñas reales
