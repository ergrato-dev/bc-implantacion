# 🎓 Glosario — Semana 1

| Término | Definición breve |
|---|---|
| **Servidor torre** | Servidor con gabinete vertical tipo PC, sin rack |
| **Servidor rack** | Servidor plano que se monta en un gabinete estándar de 19 pulgadas |
| **Unidad de rack (U)** | Medida de altura en un rack: 1U = 44,45 mm |
| **Servidor blade** | Tarjeta de servidor que se inserta en un chasis que comparte energía, red y refrigeración |
| **Hot-swap** | Componente que se reemplaza sin apagar el equipo |
| **Memoria ECC** | RAM que detecta y corrige errores de bit |
| **BMC / IPMI** | Controlador de administración remota fuera de banda (iDRAC, iLO) |
| **RAID** | Combinación de varios discos para ganar rendimiento o tolerancia a fallos |
| **Striping** | Reparto de datos en franjas entre varios discos |
| **Mirroring** | Copia idéntica de los datos en dos o más discos |
| **Paridad** | Cálculo que permite reconstruir los datos de un disco perdido |
| **IOPS** | Operaciones de entrada/salida por segundo que soporta un disco |
| **Requisito mínimo** | Recurso con el que el software arranca y responde |
| **Requisito recomendado** | Recurso con el que el software opera con la carga esperada y margen |
| **vCPU** | Núcleo de procesador virtual asignado a una VM o instancia en la nube |
| **Licencia permisiva** | Permite usar, modificar y cerrar el código conservando el aviso (MIT, BSD, Apache) |
| **Copyleft** | Obliga a distribuir las obras derivadas con la misma licencia (GPL) |
| **Source-available** | Código visible con restricciones de uso; no es open source según la OSI (SSPL, BSL) |
| **CAL** | Licencia de acceso de cliente requerida por cada usuario o dispositivo en software comercial |
| **Hipervisor** | Software que crea y administra máquinas virtuales |
| **Hipervisor tipo 1** | Se instala directo sobre el hardware (ESXi, Proxmox VE, KVM) |
| **Hipervisor tipo 2** | Se ejecuta como aplicación sobre un sistema operativo (VirtualBox) |
| **Contenedor** | Proceso aislado que comparte el kernel del anfitrión |
| **Snapshot** | Estado guardado de una VM para volver a él |
| **LTS** | Versión con soporte de largo plazo |
| **Fin de soporte (EOL)** | Fecha a partir de la cual una versión deja de recibir parches |
