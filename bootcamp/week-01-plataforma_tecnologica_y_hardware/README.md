# 📚 Semana 01 — Plataforma Tecnológica y Hardware

> 🚧 Esqueleto — contenido de teoría, prácticas y proyecto pendiente.

---

## 🎯 Objetivos de Aprendizaje

Al finalizar esta semana, el aprendiz será capaz de:

1. Diferenciar servidores rack, blade y torre, y los niveles RAID 0/1/5/10
2. Dimensionar CPU, RAM, disco e IOPS a partir de las características del software
3. Clasificar el software de servidor (web, aplicación, base de datos, proxy) y su licenciamiento (GPL, MIT, Apache, SSPL, comercial)
4. Comparar hipervisores tipo 1 y tipo 2 (VMware, Proxmox, KVM) frente a contenedores
5. Seleccionar el sistema operativo de servidor (Ubuntu Server LTS / Debian) y verificar sus requisitos mínimos
6. Verificar con un script los requisitos mínimos de hardware del proyecto real

## 📝 Contenidos

- Hardware de servidores: rack, blade, torre, arreglos de discos (RAID)
- Dimensionamiento y requisitos mínimos del software desarrollado

- Virtualización (VMware, Proxmox, KVM) vs contenedores
- Sistemas operativos de servidor: Ubuntu LTS / Debian; Windows Server solo comparativo
