# 📚 Semana 06 — Seguridad, Usuarios y Permisos

> 🚧 Esqueleto — contenido de teoría, prácticas y proyecto pendiente.

---

## 🎯 Objetivos de Aprendizaje

Al finalizar esta semana, el aprendiz será capaz de:

1. Crear usuarios y grupos en Linux y asignar privilegios con `sudo`
2. Endurecer el acceso: SSH por llave, firewall UFW
3. Definir roles en PostgreSQL con mínimo privilegio
4. Gestionar secretos sin exponerlos en el repositorio
5. Automatizar un respaldo cifrado (restic + cron) y probar su restauración
