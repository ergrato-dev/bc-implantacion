# Práctica 03 — Acta de Entrega y Socialización

<!-- 📝 Instrucción: práctica en equipos, con los resultados de las prácticas 01 y 02. La parte 3
se hace entre dos equipos que se presentan mutuamente. -->

## Objetivo

Redactar el acta de entrega de la app de referencia con niveles de servicio que se puedan
cumplir, y ensayar la presentación de resultados.

## Duración estimada

90 minutos.

## 1. Acta de entrega

Con la plantilla [`acta-de-entrega.md`](../../3-proyecto/starter/acta-de-entrega.md), redacta el
acta de la app de referencia para la Biblioteca Municipal (cliente sintético) usando:

- la decisión y los defectos de la práctica 01;
- el resultado del simulacro de la práctica 02;
- las secciones 8 y 9 del [plan de la app de referencia](../../../../referencia/docs/plan-implantacion.md).

Supón este equipo de soporte: dos personas, en horario de oficina, con la app en Render (plan
gratuito) y la base en Neon (plan gratuito).

- [ ] ¿Qué disponibilidad mensual puedes firmar con ese plan de Render? (Semana 4: suspensión
      por inactividad.) Calcula cuántas horas sin servicio al mes permite tu cifra.
- [ ] ¿Qué tiempo de primera respuesta P1 puedes cumplir un sábado? ¿Qué escribes en el acta?
- [ ] La sección de accesos, ¿contiene algún secreto? Debe listar **qué** se transfiere y **cómo**.

## 2. Revisión cruzada del acta

Intercambia el acta con otro equipo. Cada uno revisa la del otro como si fuera el cliente:

| Pregunta | Sí / No | Observación |
|---|:---:|---|
| ¿Queda claro qué versión se entrega y dónde corre? | | |
| ¿Los defectos abiertos tienen fecha de corrección? | | |
| ¿Los niveles de servicio son medibles? | | |
| ¿Algún compromiso parece imposible con los recursos descritos? | | |
| ¿La garantía dice qué **no** cubre? | | |
| ¿Hay algún secreto o dato personal? | | |

## 3. Ensayo de la socialización

Cada equipo presenta los resultados de la implantación de la app de referencia en **10 minutos**
con la estructura de la teoría 04 (sección 4), incluida la demostración en vivo. El otro equipo
cronometra y da retroalimentación:

| Aspecto | Observación concreta |
|---|---|
| ¿Mostró resultados con evidencia (tiempos, huellas, enlaces)? | |
| ¿Presentó un problema encontrado y cómo se resolvió? | |
| ¿Explicó riesgos y pendientes? | |
| ¿Terminó a tiempo? | |
| Una mejora concreta | |

## ✅ Checklist

- [ ] Acta completa con aceptación, simulacro, niveles de servicio y accesos (sin secretos)
- [ ] Niveles de servicio justificados con los recursos y planes disponibles
- [ ] Acta revisada por otro equipo y corregida
- [ ] Presentación de 10 minutos ensayada con retroalimentación
