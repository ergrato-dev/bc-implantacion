# 🎓 Glosario — Semana 3

| Término | Definición breve |
|---|---|
| **Hosting** | Servicio que mantiene un software accesible en Internet |
| **Hosting estático** | Aloja solo archivos HTML/CSS/JS, normalmente con CDN y HTTPS incluidos |
| **Hosting compartido** | Varios clientes en el mismo servidor, con panel de control |
| **VPS** | Servidor privado virtual: una VM con acceso de administrador |
| **Servidor dedicado** | Servidor físico completo alquilado a un solo cliente |
| **PaaS** | Plataforma que ejecuta tu código o contenedor sin que administres el servidor |
| **CMS** | Gestor de contenidos: software para publicar contenido sin conocimientos técnicos |
| **CMS headless** | CMS que solo expone una API; el frontend es independiente |
| **Dominio** | Nombre legible que identifica un sitio en Internet |
| **TLD** | Dominio de nivel superior (`.com`, `.co`, `.org`) |
| **Registrador** | Empresa a través de la cual se registra y renueva un dominio |
| **DNS** | Sistema que traduce nombres de dominio a direcciones IP |
| **Resolvedor** | Servidor DNS que busca respuestas en nombre del cliente y las guarda en caché |
| **Servidor autoritativo** | Servidor DNS que tiene la respuesta oficial de un dominio |
| **Registro A / AAAA** | Asocia un nombre a una IPv4 / IPv6 |
| **Registro CNAME** | Hace que un nombre sea alias de otro |
| **Registro TXT** | Texto asociado al dominio: verificación, políticas de correo |
| **TTL** | Tiempo que una respuesta DNS puede permanecer en caché |
| **Reverse proxy** | Servidor que recibe las peticiones y las reenvía al servicio interno correspondiente |
| **Virtual host** | Varios sitios en un mismo servidor, diferenciados por nombre de dominio |
| **Encabezado Host** | Campo de la petición HTTP con el nombre de dominio solicitado |
| **X-Forwarded-For** | Encabezado con la IP original del cliente cuando hay un proxy |
| **TLS / HTTPS** | Cifrado de la comunicación web con verificación de identidad del servidor |
| **Certificado** | Documento digital firmado por una CA que prueba la identidad de un dominio |
| **CA** | Autoridad de certificación |
| **Let's Encrypt** | CA gratuita y automatizada |
| **ACME** | Protocolo para obtener y renovar certificados automáticamente |
| **FTP** | Protocolo antiguo de transferencia de archivos, sin cifrado |
| **FTPS** | FTP con TLS |
| **SFTP** | Transferencia de archivos sobre SSH |
| **Chroot** | Encierra a un usuario en una carpeta que ve como raíz del sistema |
| **Llave SSH** | Par de llaves (privada y pública) para autenticarse sin contraseña |
| **rsync** | Herramienta que sincroniza carpetas enviando solo las diferencias |
