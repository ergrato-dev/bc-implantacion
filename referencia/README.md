# 🧪 App de Referencia

> 🚧 Pendiente de implementar.

Aplicación común sobre la que se hacen todas las prácticas (`2-practicas/`) del bootcamp. Su
objetivo no es enseñar a programar sino tener un software realista que implantar: requisitos
de hardware, base de datos que migrar y respaldar, servicios que configurar y desplegar.

| Componente | Tecnología |
|---|---|
| Backend | FastAPI |
| Frontend | React |
| Base de datos | PostgreSQL |
| Orquestación | Docker Compose |

Requisitos: dockerizada, con healthcheck en cada servicio, migraciones versionadas y datos
semilla sintéticos.
